# Savva · ساڤا — сайт кофейни в Медине

Одностраничник кофейни specialty-кофе **Savva** (Бир Усман, Медина). Языки — арабский (справа налево) и английский, переключатель в шапке. Сборки нет: открыл `index.html` — работает.

```
node dev-server.js      → http://localhost:8175
node tools/check.mjs pc en out    — проверка в headless Chrome (pc|phone, en|ar)
```

## Что где

| Файл | Что там |
|---|---|
| `assets/js/data.js` | **Весь контент**: меню и цены, часы, контакты, отзывы, тексты на двух языках, галерея |
| `assets/js/app.js` | Поведение: заставка, полёт в букву, меню, подбор напитка, день, латте-арт |
| `assets/css/style.css` | Оформление |
| `assets/img/brand/` | Логотип-маска SAVVA, ветка кофе, знак риала, иконка вкладки — всё из PDF-меню кафе |
| `assets/img/photos/` | Фото с Google Maps (`g00…g09`) и из Instagram (`p_…`) |
| `assets/video/` | Рилсы из Instagram: наливают кофе (`pour-720/480`), поднос (`tray-540`) |
| `assets/fonts/` | Readex Pro и Reem Kufi, локально |

## Что заменить или проверить

| Что | Где | Сейчас |
|---|---|---|
| Цены и калории | `data.js → menu` | Переписаны из PDF-меню по QR-коду (сентябрь 2026) |
| Опечатки меню | `data.js → menu` | «FLAT WAIT» → Flat White, «WAIT MOCAH» → White Mocha; арабские названия как в меню |
| Часы | `data.js → hours` | С Google Maps: сб–чт 06:30–02:00, пт 13:00–02:00 |
| WhatsApp и телефон | `data.js → contacts` | +966 56 437 0303 (из Linktree и Google) |
| Рейтинг | `data.js → contacts.rating/reviews` | 4.7 и 736 — на 27.09.2026 |
| Подпись разработчика | `data.js → credit` | `SAUDI MADE`; пустая строка скрывает |
| Карта | `data.js → contacts.mapEmbed` | Код «Поделиться → Встроить карту»; `{lang}` подставляется сам |

## Откуда мотивы

| Элемент | Что это |
|---|---|
| Три зерна в заставке | Три точки буквы ڤ в логотипе «ساڤا» — падают кофейными зёрнами и садятся на место |
| Буквы SAVVA с видео | Логотип из их меню, внутри — их же рилс; при прокрутке камера влетает в букву V |
| Арки у фото и карты | Арочные окна и двери фасада кафе |
| Рамка-«зерно» | Ниша в форме зерна у входа с надписью SAVVA |
| Ветка кофе | Гравюра из PDF-меню кафе |
| Лента-орнамент | Саду — бедуинское ткачество (наследие ЮНЕСКО), кафе использовало его в посте ко Дню Саудовской Аравии |
| Кубик QR | Деревянный кубик с меню на их столиках |
| Палитра | Шалфей и крем из меню, эспрессо, дерево подносов |

## Фишки

- «Один день в Savva» — солнце тянется по дуге 06:00 → 02:00, небо меняется, точка — время в Медине сейчас.
- Подбор напитка: три нажатия → стакан наполняется цветом напитка, заказ в WhatsApp с готовым текстом.
- Латте-арт пальцем, бариста рисует сердце / тюльпан / розетту, «Сохранить» — PNG.
- Статус «Открыто сейчас» по времени Медины (шапка и первый экран).
- Нажать на «ساڤا» на первом экране или на значок на карте — дождь из зёрен.
- Ушёл со вкладки — заголовок «☕ Your coffee is getting cold…».
- Заставка показывается при каждой загрузке, стартует только на видимой вкладке, есть «Пропустить» и аварийный выход через 10 с.
